# LK001: preprocessing-fit-before-split

**Severity:** error | **Default confidence:** high

## What it detects

A scaler, imputer, encoder, PCA or similar transformer is fitted (`fit` / `fit_transform`) on the full dataset, and a train/test split happens later in the file. leakray tracks the role of each variable (`full`, `train`, `test`) and the estimator class behind each `.fit` call.

## Why it leaks

The transformer learns statistics (mean, variance, category list, principal axes) from rows that will later be in the test set. The training features then carry information about the test set, and the test score is slightly optimistic. With small data or heavy-tailed features the gap can be large, and it never shows up in the notebook.

## Bad

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

df = pd.read_csv("data.csv")
X, y = df.drop(columns=["label"]), df["label"]
X = StandardScaler().fit_transform(X)          # LK001: sees all rows
X_train, X_test, y_train, y_test = train_test_split(X, y)
```

## Good

```python
from sklearn.pipeline import make_pipeline

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0)
model = make_pipeline(StandardScaler(), LogisticRegression())
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
```

## When it can be wrong

leakray reads names and syntax; it does not run your code or see your data.

- Only estimators leakray recognises as learning from data are checked. A custom transformer with an unusual class name is missed.
- If the data was split on disk in another file, there is no split in this file and nothing is reported.
- A transformer fitted on full data for a deliberately transductive, unsupervised setting (no test evaluation) is still reported; suppress it.

## Suppress

On the flagged line:

```python
X = StandardScaler().fit_transform(X)  # leakray: ignore[LK001]
```

For a whole file, add `# leakray: ignore-file[LK001]` anywhere in it. To turn the rule off for a project, use `ignore = ["LK001"]` under `[tool.leakray]` in `pyproject.toml`.

# LK014: groupby-transform-before-split

**Severity:** warning | **Default confidence:** medium (low for frequency encoding)

## What it detects

A group aggregate or frequency feature is computed over the full data before the split: `df.groupby(k)[col].transform("mean")`, `groupby().rank()` used as a feature, a group aggregate (`mean`, `std`, `count` ...) merged or mapped back onto the frame, `value_counts()` mapped back as a feature (low confidence), or a column normalised with its own full-data `.mean()` / `.std()` / `.max()` (low). Transforms that only look backwards (`shift`, `cumsum`, `cumcount`, `diff`, `ffill`) are not reported, and neither are aggregates that are only printed.

## Why it leaks

The statistic for a group includes rows that end up in the test set. The effect is weaker than target encoding, because the target is not used, but the training features still carry information about test rows, and counts reveal how often a test row's category appears.

## Bad

```python
df["city_avg_rooms"] = df.groupby("city")["rooms"].transform("mean")     # LK014
df["city_freq"] = df["city"].map(df["city"].value_counts())
X_train, X_test, y_train, y_test = train_test_split(X, y)
```

## Good

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0)
means = X_train.groupby("city")["rooms"].mean()
X_train["city_avg_rooms"] = X_train["city"].map(means)
X_test["city_avg_rooms"] = X_test["city"].map(means).fillna(means.mean())
```

## When it can be wrong

leakray reads names and syntax; it does not run your code or see your data.

- Frequency encoding using all available unlabeled data is sometimes done on purpose. That can be defensible in some settings and the rule is only a warning; suppress it when deliberate.
- If the aggregate uses the target column, [LK008](LK008.md) reports it instead.
- Group transforms on a frame already split under an unfamiliar name may be reported.

## Suppress

On the flagged line:

```python
df["city_avg_rooms"] = df.groupby("city")["rooms"].transform("mean")  # leakray: ignore[LK014]
```

For a whole file, add `# leakray: ignore-file[LK014]` anywhere in it. To turn the rule off for a project, use `ignore = ["LK014"]` under `[tool.leakray]` in `pyproject.toml`.

# LK007: feature-selection-before-split

**Severity:** error | **Default confidence:** high

## What it detects

Supervised feature selection that uses `y` (SelectKBest, RFE, SelectFromModel, mutual information, `f_classif`, `chi2`, or a correlation with the target) runs on the full data before a split or cross-validation.

## Why it leaks

The selector picks the features that best predict the labels, including the labels of test rows. The chosen features are tailored to the test set before the model sees it. With many features and few rows, even random data then scores far above chance.

## Bad

```python
from sklearn.feature_selection import SelectKBest, f_classif
X_sel = SelectKBest(f_classif, k=20).fit_transform(X, y)    # LK007
scores = cross_val_score(model, X_sel, y)
```

## Good

```python
from sklearn.pipeline import make_pipeline

pipe = make_pipeline(SelectKBest(f_classif, k=20), model)
scores = cross_val_score(pipe, X, y)
```

## When it can be wrong

leakray reads names and syntax; it does not run your code or see your data.

- Unsupervised selection (variance threshold, dropping constant columns) does not use `y` and is not reported, but this is judged from the function name only.
- Correlation with the target is recognised through `corr` on a target-like column. A manual selection step written another way can be missed.
- Selection based on domain knowledge or on a separate earlier study is fine, and leakray cannot see that; suppress.

## Suppress

On the flagged line:

```python
X_sel = SelectKBest(f_classif, k=20).fit_transform(X, y)  # leakray: ignore[LK007]
```

For a whole file, add `# leakray: ignore-file[LK007]` anywhere in it. To turn the rule off for a project, use `ignore = ["LK007"]` under `[tool.leakray]` in `pyproject.toml`.

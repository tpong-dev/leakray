# LK006: oversampling-before-split

**Severity:** error | **Default confidence:** high

## What it detects

SMOTE, random over- or under-sampling or another imbalanced-learn sampler runs `fit_resample` on the full data while a train/test split or cross-validation comes later in the file. Hand-written upsampling on the full data is also flagged: `sklearn.utils.resample(..., replace=True)` (high confidence) and `df.sample(replace=True)` or `frac > 1` (medium).

## Why it leaks

Resampling before the split puts synthetic points built from test rows into the training data, and puts near-copies of training rows into the test set. The model is partly tested on data it was constructed from, so minority-class recall and similar scores look much better than they are.

## Bad

```python
from imblearn.over_sampling import SMOTE
X, y = SMOTE().fit_resample(X, y)                       # LK006
X_train, X_test, y_train, y_test = train_test_split(X, y)
```

## Good

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=0)
X_tr, y_tr = SMOTE().fit_resample(X_train, y_train)

# or, for CV
from imblearn.pipeline import make_pipeline
model = make_pipeline(SMOTE(), LogisticRegression())
```

## When it can be wrong

leakray reads names and syntax; it does not run your code or see your data.

- Sampler classes are recognised by name. Hand-written resampling through other means (for example `np.random.choice` on indices) is not detected; `resample(replace=False)` is treated as downsampling and ignored.
- If the split was made in another module and this file only handles the training part, a variable named `X` may still be seen as `full`; use `X_train` / `train_df` names or suppress.
- Resampling the full data for a purpose with no evaluation (for example exploration) is reported.

## Suppress

On the flagged line:

```python
X, y = SMOTE().fit_resample(X, y)  # leakray: ignore[LK006]
```

For a whole file, add `# leakray: ignore-file[LK006]` anywhere in it. To turn the rule off for a project, use `ignore = ["LK006"]` under `[tool.leakray]` in `pyproject.toml`.

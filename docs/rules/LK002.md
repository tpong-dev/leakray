# LK002: random-split-on-time-series

**Severity:** warning | **Default confidence:** high (medium when the datetime evidence is weak)

## What it detects

A random `train_test_split`, or a shuffled K-fold, on data that looks time-ordered: a column parsed with `parse_dates`, `pd.to_datetime`, a `DatetimeIndex`, or a column with a date-like name. The finding message quotes the line that gave the evidence.

## Why it leaks

With a random split the model trains on rows from the future and is tested on rows from the past. Neighbouring days are strongly correlated, so a test row nearly always has a near-twin in training. The score measures interpolation, while production needs extrapolation forward in time, so the real error is higher.

## Bad

```python
df = pd.read_csv("sales.csv", parse_dates=["date"])
X, y = df.drop(columns=["sales"]), df["sales"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)   # LK002
```

## Good

```python
df = pd.read_csv("sales.csv", parse_dates=["date"]).sort_values("date")
cut = df["date"].quantile(0.8)
train, test = df[df["date"] <= cut], df[df["date"] > cut]

# for cross-validation
from sklearn.model_selection import TimeSeriesSplit
cv = TimeSeriesSplit(n_splits=5)
```

## When it can be wrong

leakray reads names and syntax; it does not run your code or see your data.

- A date column that is only a plain feature (for example a birth date) triggers the datetime hint although the rows are not a time series. Confidence is lower in that case.
- Rows that are time-ordered but have no date column or datetime parsing in the file are not detected.
- `shuffle=False` on already sorted data is accepted, but leakray cannot check that the data is in fact sorted.

## Suppress

On the flagged line:

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)  # leakray: ignore[LK002]
```

For a whole file, add `# leakray: ignore-file[LK002]` anywhere in it. To turn the rule off for a project, use `ignore = ["LK002"]` under `[tool.leakray]` in `pyproject.toml`.
